# 👁️ Computer Vision (`computer-vision`)

Covers image processing, deep visual architectures, object detection, segmentation, and generative vision models.

## Topics Covered
- **Classical CV**: Filters, convolutions, edge detection (Sobel, Canny), morphological operations, feature descriptors (SIFT, ORB).
- **Classification**: ResNet, EfficientNet, MobileNet implementations.
- **Object Detection**: Single-shot vs two-stage detectors (YOLO, Faster R-CNN), Non-Maximum Suppression (NMS), IoU calculations.
- **Semantic & Instance Segmentation**: U-Net architecture, FCN, Mask R-CNN.
- **Generative & Vision Transformers**: GANs, Latent Diffusion Models (Stable Diffusion mechanics), Vision Transformers (ViT).
