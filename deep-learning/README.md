# 🧠 Deep Learning (`deep-learning`)

Focuses on Neural Network foundations, custom automatic differentiation engines (Autograd), PyTorch models, initialization schemes, and loss surface analysis.

## Topics Covered
- **Scalar Autograd Engine**: Building a mini-micrograd engine from scalar computational graphs.
- **Neural Network Primitives**: Custom implementations of `Linear`, `Conv2D`, `ReLU`, `BatchNorm`, `Dropout`, `Softmax`.
- **Architectures**: MLPs, ResNet variants, Recurrent Neural Networks (LSTM/GRU), Transformer Encoders/Decoders.
- **Optimization Tricks**: Learning rate schedulers, AdamW optimizer mechanics, mixed-precision training.

## Structure
- `notebooks/`: Interactive training loops, loss landscape visualization, activation statistics.
- `src/deep_learning/`: Reusable PyTorch modules, custom layers, engine primitives.
