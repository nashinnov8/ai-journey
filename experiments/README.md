# 🧪 Experiments (`experiments`)

Sandbox playground for testing multi-domain ideas, running speed/memory benchmarks, validating paper claims, or prototyping features before promoting them into dedicated subprojects or `shared/`.

## Guideline
- Treat files here as transient or semi-structured prototypes.
- When an experiment reaches maturity, refactor the production logic into `src/` modules inside the appropriate domain subproject.
