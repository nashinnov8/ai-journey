# 🤖 Large Language Models (`llm`)

Explores LLM internal mechanics, tokenizer construction, decoder-only transformer implementations, PEFT fine-tuning, Retrieval-Augmented Generation (RAG), and model quantization techniques.

## Core Pillars
1. **Tokenization from Scratch**: Byte Pair Encoding (BPE) algorithm implementation.
2. **GPT Architecture from Scratch**: Multi-head self-attention, rotary positional embeddings (RoPE), RMSNorm, and KV-cache decoding.
3. **Parameter-Efficient Fine-Tuning**: LoRA (Low-Rank Adaptation) and QLoRA mechanics.
4. **Retrieval-Augmented Generation (RAG)**: Vector database integration, semantic search, hybrid retrieval.
5. **Alignment & Preference Optimization**: RLHF, DPO (Direct Preference Optimization).
6. **Inference Acceleration**: FlashAttention, PagedAttention, vLLM, and GGUF quantization.
