# 📐 Mathematics for Artificial Intelligence (`math`)

This subproject covers fundamental mathematical pillars for Machine Learning and Deep Learning:

- **Linear Algebra**: Matrix decompositions (SVD, Eigenvalue decomposition, LU, QR), vector spaces, norms, projections.
- **Multivariable Calculus**: Gradients, Jacobians, Hessians, automatic differentiation logic, chain rule.
- **Probability & Statistics**: Probability distributions, Maximum Likelihood Estimation (MLE), Maximum A Posteriori (MAP), Bayesian inference, hypothesis testing.
- **Convex Optimization**: Gradient descent, Newton-Raphson method, Lagrange multipliers, KKT conditions.

## Structure
- `notebooks/`: Mathematical explorations and visualizations (e.g. SVD image compression, gradient flow visualizers).
- `src/math_learning/`: NumPy & SciPy implementations of mathematical operations from first principles.
