# ⚙️ MLOps (`mlops`)

Covers production engineering practices for machine learning systems:

- **Experiment Tracking**: MLflow & Weights & Biases metric logging, artifact storage, hyperparameter run tracking.
- **Pipeline Orchestration**: Data pipelines, retraining schedules, DVC version control.
- **Model Serving APIs**: High-throughput FastAPI endpoints, batch inference jobs, Triton Inference Server setup.
- **Model Quality & Drift**: Data drift detection, concept drift monitoring, performance degradation checks.
- **Containerization**: Production Dockerfiles, docker-compose environments, multi-stage builds.
