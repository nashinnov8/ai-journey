# 🗣️ Natural Language Processing (`nlp`)

Explores classical NLP techniques, distributional semantics, sequence modeling, and encoder-decoder mechanisms.

## Core Topics
- **Preprocessing & Representation**: TF-IDF, CountVectorizer, Subword Tokenization, Stemming & Lemmatization.
- **Word Embeddings**: Word2Vec (Skip-gram & CBOW), GloVe, FastText from scratch.
- **Sequence Processing**: Recurrent Neural Networks (RNN), LSTMs, Bidirectional GRUs for Sentiment Analysis & Named Entity Recognition (NER).
- **Attention & Sequence-to-Sequence**: Bahdanau & Luong Attention mechanisms, Neural Machine Translation (NMT).
