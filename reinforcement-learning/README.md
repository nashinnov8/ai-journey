# 🕹️ Reinforcement Learning (`reinforcement-learning`)

Covers agent-environment decision processes, value-based methods, and policy gradient algorithms.

## Core Topics
- **Foundations**: Markov Decision Processes (MDPs), Bellman Equations, Dynamic Programming (Policy/Value Iteration).
- **Model-Free Value Learning**: Q-Learning, SARSA, Deep Q-Networks (DQN, Double DQN, Dueling DQN).
- **Policy Gradient Methods**: REINFORCE, Actor-Critic (A2C/A3C), Proximal Policy Optimization (PPO), Soft Actor-Critic (SAC).
- **Environments**: Farama Gymnasium (CartPole, LunarLander, MuJoCo robotics).
